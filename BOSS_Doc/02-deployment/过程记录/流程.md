

## 流程

```
① sync+score         ② fetch              ③ aggregate        ④ cloud sync
python -m pipeline    python batch.py       aggregator.py      HTTP POST
    ↓                    ↓                     ↓                  ↓
 rss-archive.db     _fetch_tmp.jsonl      event_registry    PostgreSQL
    ↓                    ↓                     ↓                  ↓
 news_intel.db       import → DB           71 events           ⚠️ 缺列阻塞
```

### 命令

| 步骤 | 一键 | 分步 |
|------|------|------|
| 同步+评分 | `python -m news_intel.pipeline --hours 48` | — |
| 同步+抓取 | `python -m news_intel.pipeline --hours 48 --fetch` | 超时则分步 |
| 聚合 | pipeline 自动完成 | 见文档 |
| 健康检查 | `python news_intel/pipeline_check.py check` | — |
| 查看日志 | `news_intel/_fetch_tmp.jsonl` | — |
| 云端同步 | ⚠️ 阻塞 | PG 表缺列 |

完整操作文档：`docs/PIPELINE_OPS.md`。当前唯一阻塞是云端 PG 缺列，是否执行 ALTER TABLE？
