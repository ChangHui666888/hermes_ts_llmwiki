
#### 1.7 SAO Fingerprint 维度

```
fingerprint = {subject, action, object, event_type, primary_topic, secondary_topic, country, anchor}
```

#### 1.8 fingerprint_score 分值

```python
Location不同 → 0 (硬约束)
Anchor相同  → 100 (强制满分)
Action相同  → +35 (OTHER除外)
Subject相同 → +25
Object相同  → +20
Topic相同   → +15 (primary) / +5 (secondary)
EventType同 → +5
```

#### 1.9 三阶段阈值

```python
EVENT_THRESHOLD = 50    # Phase 1: Article → Event
MERGE_THRESHOLD = 70    # Phase 2: Event → Event

```

#### 1.10 Location 硬约束

```python
if country_a and country_b and country_a != country_b:
    return 0   # 不同国家绝不聚合
```

#### 1.11 HTML 过滤

```python
HTML含量 > 30% → 丢弃 description, 只用标题
```

#### 1.12 日期解析

```python
ISO格式 → fromisoformat()
RSS格式 → email.utils.parsedate_to_datetime()
不可解析 → None (跳过时间窗口检查)
```

### 二、L9 洞察生成 (generator.py)

#### 2.1 INSIGHT_PROMPT

```
分析以下事件，输出JSON:
{
  "summary": "事件一句话概述(50字)",
  "impact_analysis": "对市场/行业/地缘的直接影响(100字)",
  "drivers": "关键驱动因素(50字)",
  "sentiment": "positive/neutral/negative",
  "confidence": 0.0-1.0
}

事件标题: {title}
涉及实体: {entities}
关联文章数: {count}
```

#### 2.2 调用参数

| 参数 | Qwen3 | DeepSeek |
|------|:--:|:--:|
| 模型 | `qwen3-1.7b-instruct` | `deepseek-v4-flash` |
| max_tokens | 400 | 500 |
| 超时 | 30s | 30s |
| temperature | — | 0.1 |

#### 2.3 路由规则

```python
impact_level=="HIGH" OR tier=="A" → DeepSeek
其余 → Qwen3
无 DEEPSEEK_API_KEY → 降级 Qwen3
```
