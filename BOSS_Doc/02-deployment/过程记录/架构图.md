### Schema (21 字段)

[完整 JSON Schema](<C:/Users/ChangHui/AppData/Local/hermes/profiles/outside-deepdeek/skills/research/search-engine-v2/scripts/news_intel/SCHEMA.md>)

```
event_id      subject{name, type}  action{type, detail}  object{name, type}
event_type    event_time           location{country}
source{primary, authority, count}  doc_refs[]
actors[{entity, type, role}]       title                summary
keywords[]    confidence           coherence             extraction_method
related_entities[{name, type}]     article_count         article_ids[]
stage         first_seen           last_updated
```

### 核心公式

```
confidence = 0.4×(authority/20) + 0.3×(coherence/100) + 0.2×(diversity) + 0.1×(volume)
stage = breaking(<2h) | developing(2-24h) | active(24h-7d) | stable(7-30d) | closed(>30d)
actors = first_entity→Initiator | object_match→Target | others→Participant
```
