## 二、发现的问题（按严重度）

### 🔴 P1 高影响

#### 1. 聚合同主体跨主题错并（ISS-20260808-004）
- **实例**: `EVT-20260807-082` 把 "Trump 谈伊朗战争" + "Trump 谈古巴" 并成 1 事件（summary 用 `|` 硬拼接）
- **根因**: `fingerprint_score` 基于实体对重叠；**主题硬约束被同主体绕过**（`subject 相同 → 不阻断`）；无 coherence 下限拒绝（<75 只降 impact 不拆事件）；anchor 相同 → 无条件 100 分
- **影响**: 事件质量差，误导情报判断

#### 2. 词边界误标系统性存在（已修部分，未修全）
- **已修**: war/UN/5G/coup/NATO/nuclear/election → `_WORD_BOUNDARY_FORCE` 或长度启发式
- **实例**: `election`⊂`Selection`（LLM 论文误判政治）、`nuclear`⊂`NuclearDiffusion`（ML 模型名误判核能）、`war`⊂`hardware`/`forward`、`EV`⊂`every`/`event`、`oil`⊂`soil`
- **当前是点状修补**，无系统性扫描 → 同类误标仍可能潜伏（如 `market`⊂`marketing`、`rate`⊂`corporate`）
- **影响**: 学术/技术文本评分虚高（500 篇测试已修复 1591 处误标，仍非完备）

### 🟡 P2 中影响

#### 3. 评分整体偏保守
- **现象**: 平均 27.9、中位数 20、A 级=0、B 级仅 4.6%
- **根因**: ① impact 跨类取最高不累加（防标题党但压低多主题文章）② 词边界修复去掉虚高分 ③ 来源分(~15)在总分中占比主导 ④ 实体/市场命中率低（学术样本）
- **影响**: LLM 增强覆盖低（95% 走规则），深度情报少

#### 4. 分类统计口径：关键词 vs 主体严重不一致
- **现象**: 政治影响 关键词口径仅 0.6%(30)，但主体(机构/人物实体)口径 6.7%(337)——差 11 倍
- **根因**: 23 个机构词(国务院/美联储/证监会)从关键词移到 organizations 实体后，关键词口径失去政治信号
- **影响**: 单一口径统计会严重低估政治/全球局势影响

#### 5. 大宗商品统计受资产映射噪音
- **现象**: 大宗商品关键词命中仅 0.1%(3)，但 market_assets 油气股路径 109 篇(2.2%)——后者含大量 `war→Exxon/Chevron` 映射噪音（战争新闻带出油气股）
- **影响**: 无法用 market_assets 精确统计大宗商品

### 🟢 P3 低影响/优化

#### 6. 中文粗分词 → velocity 判同偏低
- "美联储宣布降息" 是 1 个 token，相似中文标题 Jaccard 仅 0.33 < 0.5 → 漏判同事件
- 跨语言（中英）指纹零交集 → 同一事件中英报道不计 velocity

#### 7. velocity O(n²) 性能
- 5000 篇 velocity 计算 123s（嵌套全量比较）→ 大样本慢

#### 8. 关键词覆盖不均衡
- 科技(ai_tech) 15.4% vs 大宗商品 0.1% vs 市场情绪 1.2% ——大宗商品/市场情绪关键词偏少

## 三、改进方案（分优先级）

### 🚀 短期（立即可做）

| # | 方案 | 收益 | 工作量 |
|---|------|------|:--:|
| S1 | **系统性词边界扫描**: 对 event_keywords + asset_graph 全部英文关键词做子串碰撞检测（如 `election`⊂`selection`），碰撞词批量加入 `_WORD_BOUNDARY_FORCE` 或统一词边界 | 消除残余误标 | 小（脚本+人工复核） |
| S2 | **聚合内容相似度门**（ISS-004 方案①）: 同主体但主主题不同的成员，需标题词集 Jaccard ≥ 阈值才并入 | 根治错并 | 中 |
| S3 | 提交已修复的 nuclear/election 词边界 | 立即生效 | 无 |

### 📈 中期（需产品决策）

| # | 方案 | 权衡 |
|---|------|------|
| M1 | **评分校准**: ①B 级门槛 60→50（LLM 覆盖 +4%）②impact 跨类适度累加（封顶不变，防刷分仍有效）③来源权威度权重重估 | 更高覆盖 vs 成本/精度 |
| M2 | **统计口径统一**: 政治/全球局势 = 关键词 ∪ 主体实体（机构/人物/国家）；大宗商品用**专用商品词表**（排除 war→油 映射） | 口径可信 |
| M3 | **关键词扩充**: 大宗商品（油价/金价/铜/农产品/OPEC 决议）与市场情绪（投资者情绪/恐慌指数/融资余额/北向资金）补词 | 覆盖均衡 |

### 🔭 长期（架构优化）

| # | 方案 | 收益 |
|---|------|------|
| L1 | **中文分词指纹**: 引入 jieba 或基于实体库短语切分做 velocity 指纹 + 跨语言用 KB 实体 ID 归一匹配 | 中文/跨语言 velocity 准 |
| L2 | **velocity 索引化**: 指纹词倒排索引 + 时间桶（30min 窗口内只比同桶），O(n²)→O(n·k) | 5000 篇 123s→秒级 |

## 五、结论

评分引擎核心逻辑（五维 + 词边界 + 实体分类）**正确且稳定**（5000 篇 0 错误）。主要矛盾从"功能缺陷"转向"**精度与覆盖的校准**"：
1. 残余词边界误标需**系统性扫描**收尾（S1）
2. 聚合错并需**内容相似度门**根治（S2，ISS-004）
3. 评分偏保守与**统计口径**是产品级决策（M1/M2），需业务侧定调
