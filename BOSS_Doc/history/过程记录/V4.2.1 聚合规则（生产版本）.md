### 3. Entity IDF

```python
weight = type_weight × (0.2 + 0.4 × global_idf + 0.4 × topic_idf)
global_idf = log(N / freq)     # 跨批次
topic_idf = log(topic_N / topic_freq)  # 同主题内
```

### 6. SAO Fingerprint

```python
{
  subject,       # 最高权重公司/人物
  action,        # 动作检测结果
  object,        # 最高权重国家/公司
  event_type,    # 动作→事件类型映射
  primary_topic, # 最高分Topic
  secondary_topic,
  country,       # 主要国家 (hard constraint)
  participants,  # 全部参与国 (bonus)
  anchor         # "subject|action|object|topic"
}
```

### 7. fingerprint_score

```python
Location 硬约束: country不同 → return 0
Anchor 完全匹配 → return 100

Action 相同 (+25, OTHER除外)
Subject 相同 (+25)
Object 相同 (+30)
Primary Topic 相同 (+10, secondary +5)
Event Type 相同 (+10)
Participants 交集≥2 (+10, =1 +5)
```
