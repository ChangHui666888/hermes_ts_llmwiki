### 维度二：Event Impact（事件影响力，0-30分）

**方法：** 对 `title + description` 做关键词匹配，分5个领域。

**核心规则：**
- 同类关键词取最高分（不累加），不同类取最高分（不跨类累加）
- 最终 `min(max_score, 30)` 截断

| 领域 | 30分 | 28分 | 25分 | 22分 | 20分 | 18分 |
|------|------|------|------|------|------|------|
| **金融** | 降息、加息、破产、熔断 | 违约、债务危机、崩盘 | 央行、通胀、制裁、暴跌/暴涨 | GDP、汇率、油价、石油 | 财报、IPO、黄金、人民币 | 并购、美元 |
| **地缘** | 战争、政变、暗杀 | 停火、空袭、弹劾、恐怖 | 冲突、打击、和谈 | 军事、NATO | 选举、G7/G20 | 联合国 |
| **AI** | — | AGI、GPT-5 | OpenAI、出口管制、AI安全 | NVIDIA、GPU、芯片 | ChatGPT、模型发布、监管 | 机器人、自动驾驶 |
| **市场** | — | — | 央行 | 熊市 | 标普、纳斯达克、牛市 | 道指、轧空 |
| **中国** | — | 台海 | 两会、政治局、中美、南海 | 房地产、芯片、国务院 | 新能源、人民币国际化 | 一带一路 |

**示例：**

```
标题: "美联储紧急降息50基点，美股暴跌"
  → 金融.降息=30, 金融.暴跌=25, 金融.美联储=30
  → 同类取最高: 30（命中"降息"）
  → 最终: 30
```

**代码：**

```python
def score_impact(title, description):
    text = f"{title} {description}".lower()
    max_score = 0
    for category, kw_dict in event_keywords.items():
        cat_best = 0
        for keyword, score in kw_dict.items():
            if keyword.lower() in text and score > cat_best:
                cat_best = score
        if cat_best > max_score:
            max_score = cat_best
    return min(max_score, 30)
```

```python
def score_entities(title, description):
    text = f"{title} {description}"
    max_score = 0
    found = {"companies": [], "persons": [], "countries": []}
    for etype, entities in entity_weights.items():
        for name, weight in entities.items():
            if name in text:
                found[etype].append(name)
                if weight > max_score:
                    max_score = weight
    return min(max_score, 20), found
```

### 维度五：Velocity（传播速度，0-10分）

**方法：** 跨文章指纹比对——Jaccard相似度≥0.5 且 发表时间在±30分钟内。

**步骤：**

```
1. 标题取前8个实词（去停用词）→ 词集
2. 两两比较 Jaccard = |交集| / |并集|
3. Jaccard ≥ 0.5 且 |时间差| ≤ 30min → 视为同事件
4. velocity_count = 同事件报道数
5. 分数映射: 0源→0, 2源→2, 5源→5, 10+源→10
```

| velocity_count | 分数 |
|:--:|:--:|
| 1（仅自身） | 0 |
| 2-4 | 2 |
| 5-9 | 5 |
| ≥10 | 10 |

**示例：**

```
BBC:    "Trump says ceasefire is over after US and Iran trade strikes"
        词集: {trump, says, ceasefire, over, after, iran, trade, strikes}

Al Jazeera: "Trump says ceasefire over after US, Iran trade attacks"
        词集: {trump, says, ceasefire, over, after, iran, trade, attacks}

Jaccard = 7/9 ≈ 0.78 ≥ 0.5 ✅ + 时间差5分钟 ✅
→ 两篇都 velocity_count=2 → velocity=2分
```

**代码：**

```python
def compute_velocity(articles, window_minutes=30):
    for a_i in articles:
        fp_i = _make_fingerprint_set(a_i["title"])
        count = 1
        for a_j in articles:
            if a_j is a_i: continue
            fp_j = _make_fingerprint_set(a_j["title"])
            if fp_i and fp_j:
                jaccard = len(fp_i & fp_j) / len(fp_i | fp_j)
                if jaccard >= 0.5 and abs(ts_i - ts_j) <= 30min:
                    count += 1
        a_i["velocity_count"] = count
```

### 总分计算

```python
def score_article(source_name, title, description, velocity_count=0):
    src = score_source(source_name)           # 0-20
    imp, _ = score_impact(title, description)  # 0-30 (取最高关键词)
    ent, _ = score_entities(title, description) # 0-20 (取最高实体)
    mkt, _ = score_market(title, description)   # 0-20 (取最高资产)
    vel = score_velocity(velocity_count)        # 0-10

    total = src + imp + ent + mkt + vel
    total = min(total, 100)

    if total >= 85:  tier = "A"
    elif total >= 60: tier = "B"
    else:             tier = "C"

    return {total, src, imp, ent, mkt, vel, tier, entities, categories, market_assets}
```
