### 关键数字

```
200篇 RSS → 评分 → 16篇 Tier A/B (8%) → Qwen3增强 (每篇1次调用, 15s)
       → 0-1篇 Tier A → DeepSeek V4 Flash
       → L8 聚合 → 4-7个事件 (纯规则, 0.0s)
       → L9 洞察 → 4-7次 LLM 调用
       
日均 LLM 调用: 约30次 (16篇×2批×3次/篇) Qwen3 + 1-3次 DeepSeek
日均 LLM 费用: < $0.01
```
