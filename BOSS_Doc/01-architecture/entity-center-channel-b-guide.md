# Entity Center 通道 B — 人工维护实体数据 · 操作指南

> **通道 B = 实体数据的 Admin UI / CSV / API 人工维护**，用于日常补录/修正实体（新增实体、补别名/标识符、改字段、CSV 批量导入、关系维护），无需写代码、无需跑脚本。

## 2. 登录与权限

- **登录账号**：`admin@test.com` / `admin123`
- **必须登录**：未登录时只能看到页面骨架，所有数据操作返回 `401 未授权`。登录后右上角显示邮箱 + 权限徽标。
- **权限分级**（登录后按账号级别）：
  - `admin`：全部功能（含配置切换 / 合并 / Ontology 写操作）
  - `operator`：实体管理 + 候选审批
  - `readonly`：仅只读

> 日常维护用 operator 足够；只有改配置 / 合并等才需要 admin。

## 4. 常用操作

### 4.1 新增实体
1. 实体 Tab → 右上「**+ 添加实体**」。
2. 填：**名称**（必填）、类型（COMPANY/PERSON/COUNTRY/...）、子类型（可选）、重要度 0-100、国家、别名（逗号分隔）、标识符（`scheme:value` 逗号分隔，可选）、说明。
3. 点「创建」。名称重复会提示冲突（409），换名即可。

### 4.2 补标识符（最常见，重点）
标识符 = 实体的外部稳定编号（股票代码 / KB 实体 ID / ISIN 等）。补上后画像页「标识符」列才有值。

1. 实体 Tab → 搜索框输入实体名 → Enter。
2. 目标行点「**编辑**」。
3. 弹窗底部「**标识符**」输入框，按格式填 `scheme:value`，多个用逗号分隔：
   - 股票代码：`ticker:NVDA`
   - KB 实体 ID：`kb_v1_id:COMP_APPLE`
   - ISIN：`isin:US0378331005`
4. 点「保存修改」。

**⚠️ 标识符规则**：
- **全量替换**：输入框内容 = 保存后的完整集合；**清空输入框再保存 = 删除全部标识符**。
- **全局唯一**：同一 `scheme:value` 全库只能属于一个实体。被别的实体占用时保存会提示「已被其他实体占用」，需先移除占用方或换值。
- 合法 scheme：`kb_v1_id` / `ticker` / `isin` / `wikidata` / `legacy_pg_id` / `iso_alpha3` / `cik`。

### 4.3 CSV 批量操作
1. 实体 Tab →「**导出实体CSV**」→ 用 Excel/记事本打开（含表头 + 第 2 行字段说明）。
2. 按模板补行：`canonical_name`(必填) / type / subtype / importance / country / aliases(竖线`|`分隔) / **identifiers**(`scheme:value` 竖线分隔) / description / status。
3. 保存为 CSV →「**导入实体CSV**」→ 看报告（created=新建 / updated=更新 / skipped+errors=被跳过行与原因）。
4. 坏数值（如 importance 填了字母）只会跳过该行，**不中断整批**。
5. 关系批量同理：导出/导入 `relationships` CSV（from_name / to_name / relation_type / confidence / status）。

### 4.4 废弃 / 合并
- **废弃**：目标行「废弃」→ 实体状态 deprecated（不再参与解析，数据保留）。
- **启用**：deprecated 实体行「启用」→ 恢复 active。
- **合并**：source 行「合并」→ 粘贴目标实体 ID → 执行。source 标 merged，别名/标识符迁到 target。⚠️ 合并不可撤销，且**不能链式合并**（target 不能是已合并结果）。

## 5. 常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 打不开页面 | 没连 Tailscale；或 Tailscale 已断开，重新连接后刷新 |
| 页面能开但操作报 401 | 未登录。右上角登录后再操作 |
| 点操作报 403 | 当前账号权限不足（readonly），换 operator/admin 账号 |
| 保存标识符报「已被其他实体占用」 | 该 `scheme:value` 属于别的实体，换值或先释放占用方 |
| 新增实体提示冲突 | canonical_name 已存在，换名（名称不可改，重复即 409） |
| CSV 导入有行没进去 | 看报告 skipped/errors 里的原因（缺必填列 / 实体不存在 / 非法数值） |

---

## 6. 注意事项（⚠️）

1. **实体名称 canonical_name 不可修改**（标识字段），写错了只能废弃重建。
2. 标识符**全局唯一**，别给两个实体填同一个 ticker。
3. CSV 模板**用导出的为准**（含第 2 行字段说明），不要手写列名。
4. 大库导出 CSV 可能较慢（约 20+ 秒），耐心等待，勿重复点击。
5. 删除类操作谨慎：废弃/合并后数据仍保留（可追溯），但不可自动恢复原状。
